# Thai Stock Watchlist — หุ้นไทยน่าศึกษาระยะยาว

เอกสารตั้งต้นสำหรับสร้างแอปติดตามหุ้นไทย ระยะลงทุน 5–10 ปี  
ขอบเขต: สรุปจากการคัดหุ้นวันที่ 30 กันยายน 2569 โดยอ้างอิงเอกสารที่ใช้ในรอบนั้น ไม่ใช่การอัปเดตราคาและงบล่าสุด ณ วันที่เปิดไฟล์

## เป้าหมายของรายการ

เพิ่มธุรกิจที่ต่างจาก PTTEP (พลังงานต้นน้ำ) และ TTB (ธนาคาร) ซึ่งมีอยู่แล้วในพอร์ตตามข้อมูลวันที่คัดหุ้น เริ่มศึกษาจาก **ADVANC และ BDMS** เพื่อเพิ่มรายได้จากบริการสื่อสารและสุขภาพ ส่วน **CPALL และ CPN** เพิ่มโอกาสจากการบริโภคและอสังหาริมทรัพย์เชิงพาณิชย์ แต่มีความเสี่ยงจากกำลังซื้อร่วมกัน

ลำดับนี้ใช้จัดคิวศึกษา ไม่ใช่อันดับผลตอบแทนหรือสัญญาณซื้อ หุ้นทั้งสี่อยู่ในสถานะ `watch` และยังไม่มีราคาเข้าซื้อที่ผ่านการประเมิน

## แอปเวอร์ชันแรก

1. **Watchlist:** แสดงชื่อหุ้น กลุ่มธุรกิจ เหตุผลที่ติดตาม สถานะ ราคาและเวลาข้อมูล เมื่อยังไม่มีราคาให้แสดง “ยังไม่มีข้อมูล” ไม่ใช้ศูนย์แทน
2. **หน้ารายละเอียดหุ้น:** เก็บเหตุผลลงทุน ความเสี่ยง ตัวเลขสำคัญ ผลประกอบการรายไตรมาส และบันทึกว่ากำไรหรือกระแสเงินสดเปลี่ยนเพราะอะไร
3. **ประเมินราคา:** เก็บ P/E ย้อนหลัง 12 เดือน และสมมติฐานกำไรปกติแยกกัน หากใช้ราคาเป้าหมาย ให้บันทึกวิธีคำนวณและวันที่ประเมิน สำหรับหุ้นปันผลให้แยกปันผลปกติและปันผลพิเศษ
4. **สถานะติดตาม:** `watch` = ติดตาม, `review` = มีงบใหม่หรือราคาถึงช่วงที่ผู้ใช้ตั้งไว้, `hold` = ผู้ใช้ระบุว่าถืออยู่, `archived` = เลิกติดตาม การแตะช่วงราคาให้แจ้ง “ทบทวน” เท่านั้น ไม่เปลี่ยนเป็นคำสั่งซื้ออัตโนมัติ

เก็บราคาและข้อมูลงบแยกตามวันที่ พร้อมแหล่งอ้างอิงและเวลาอัปเดต ใช้เขตเวลา Asia/Bangkok สำหรับเวลาแสดงผล แยกตัวเลขจริงที่รายงานออกจากประมาณการ และตรวจเงื่อนไขการใช้ข้อมูลก่อนเชื่อมผู้ให้บริการราคา
